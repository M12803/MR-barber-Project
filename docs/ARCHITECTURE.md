# 🏛️ دليل المعمارية البرمجية (Software Architecture Guide)
## Mohamed Ramshan Barber Shop Management System (MR Barbers)

تم تصميم النظام بمعمارية طبقية حديثة ونظيفة (**Clean Layered Architecture / Domain-Driven Design**) لتوفير:
1. **أقصى درجات المرونة (Extensibility)**: سهولة إضافة موديولات جديدة أو تغيير قواعد الحسابات دون المساس بباقي أجزاء النظام.
2. **العمل بدون إنترنت (100% Offline-First)**: التطبيق يعمل بكفاءة تامة على جهاز الصالون دون الحاجة لأي اتصال بالسيرفرات أو الخدمات السحابية.
3. **سلامة ودقة العمليات المالية (Financial Immutability)**: عدم السماح بحذف أي عملية مالية مسجلة؛ أي تعديل يتم عبر طلبات تصحيح وقيد عكسي معتمد مع سجل رقابي كامل.

## 📁 هيكل المجلدات والمسؤوليات (Directory Structure)

- **`src/types/index.ts`**: يحتوي على كافة العقود والأنواع البرمجية (Contracts & Domain Models) للمستخدمين، الموظفين، الخدمات، التذاكر، السلف، المصروفات، والورديات.
- **`src/lib/`**:
  - `utils.ts`: أدوات التنسيق المالي (EGP)، التواريخ العربية، وتوليد أصوات التنبيه (Web Audio API Synthesizer).
  - `db/storage.ts`: محرك التخزين المحلي الآمن مع آلية الاشتراك (Pub/Sub) لتحديث الواجهات فور حدوث أي تغيير.
  - `db/mockData.ts`: بيانات التهيئة الأولية للمشروع لتسهيل العرض التجريبي الفوري.
- **`src/services/`**: طبقة منطق الأعمال الخالص (Business Rules & Workflows). مفصولة تماماً عن واجهات المستخدم لسهولة كتابة الاختبارات والتعديل.
- **`src/context/`**: موفر الحالة العامة (App Provider) الذي يدير المستخدم الحالي، شاشة القفل، التبديل السريع، وعرض الشاشات.
- **`src/components/ui/`**: عناصر الواجهة الأساسية المصممة بهوية الصالون الفاخرة (Buttons, Badges, Modals, Inputs).
- **`src/components/layout/`**: شريط التنقل العلوي (Header)، القائمة الجانبية (Sidebar)، وشاشات القفل والتبديل السريع.
- **`src/features/`**: شاشات الموديولات الوظيفية:
  - `pos/`: شاشة نقطة البيع السريعة وطباعة الإيصال الحراري.
  - `dashboard/`: لوحة تحكم الإدارة والمؤشرات اليومية.
  - `employee-home/`: شاشة الموظف لمتابعة إحصائياته وورديته وطلب السلف.
  - `transactions/`: سجل العمليات الشامل والفلترة.
  - `corrections/`: شاشة مراجعة طلبات التعديل والإلغاء للإدارة.
  - `employees/`: إدارة الحلاقين وتحديد قواعد العمولات (نسبة، مبلغ ثابت، راتب).
  - `services/`: إدارة قائمة الخدمات والأسعار والتصنيفات.
  - `advances/`: دورة حياة السلف والأقساط والسداد.
  - `cashbox/`: إدارة الخزينة ومطابقة نقدية الورديات وعجز/زيادة الكاش.
  - `expenses/`: إدارة المصروفات التشغيلية.
  - `reports/`: التقارير وتصدير ملف Excel متعدد الشيتات.
  - `audit/`: سجل الرقابة والأمان غير القابل للتعديل.
  - `settings/`: إعدادات الصالون وهوية النظام والنسخ الاحتياطي.

## 🔒 القواعد المالية والأمنية الصارمة (Strict Financial Rules)

1. **لا حذف للعمليات المسجلة (No Hard Deletes)**:
   - التذاكر المسجلة لا يمكن لموظف الصالون تعديلها أو حذفها.
   - في حال حدوث خطأ، يقدم الموظف طلب تصحيح (Correction Request).
   - المدير يراجع الطلب، وعند الموافقة يتم وسم التذكرة كـ `VOIDED`، ويتم إجراء قيد مالي عكسي فوري في الخزينة إن كانت العملية كاش.
2. **سجل الرقابة (Immutable Audit Trail)**:
   - كل عملية دخول، بيع، اعتماد سلفة، تسجيل قسط، أو تعديل إعدادات يتم تسجيلها في `auditLogs` مع هوية المنفذ وتوقيتها الدقيق.
3. **تصدير إكسيل مطابق للمواصفات**:
   - يتم تصدير مصنف إكسيل كامل يحتوي على 10 صفحات مفصلة بنقرة زر واحدة دون الحاجة لأي خادم أو اتصال خارجي.
